## 課程準備度檢查清單 (Readiness Checklists)

完成八週後，用以下清單評估你對不同後續課程的準備度。

### A. 財務演算法課程 (Financial algorithms coursework)

- [ ] 能正確計算 simple / log return 並解釋差異。
- [ ] 能用矩陣表示多資產報酬並計算共變異數矩陣。
- [ ] 能實作最小變異投資組合並解釋其約束。
- [ ] 能為債券與歐式選擇權（binomial）定價並解釋每一步。
- [ ] 能區分 buy-and-hold 與每期再平衡的差異。

### B. 計量經濟 / 應用迴歸課程 (Econometrics / applied regression)

- [ ] 能推導 OLS 的矩陣解 $\hat{\beta}=(X^\top X)^{-1}X^\top y$。
- [ ] 能解讀截距、beta、殘差、R-squared 與標準誤。
- [ ] 知道 heteroskedasticity 的概念與其對標準誤的影響。
- [ ] 能說明 omitted variable bias。
- [ ] 知道「迴歸係數不等於可交易訊號」。

### C. 時間序列課程 (Time-series coursework)

- [ ] 能解釋定態性與非定態的差異。
- [ ] 能計算並解讀 ACF。
- [ ] 能產生並辨識 AR(1) 與隨機漫步。
- [ ] 知道為何隨機 train/test 切分不適用於時間性資料。
- [ ] 能執行 expanding 與 rolling window 的走動式評估。

### D. 證明導向最佳化課程 (Proof-heavy optimization coursework)

- [ ] 能寫出等式約束最佳化的 Lagrangian。
- [ ] 能解釋凸性與其對「唯一最小值」的意義。
- [ ] 能用梯度與 Hessian 描述局部行為。

> **重要說明**：本路線圖對「證明導向最佳化課程」**只提供初步診斷**。它幫助你
> 確認自己是否具備基本直覺與計算能力，但**不取代**正式、以證明為主的數學
> 訓練（嚴謹的線性代數、實分析、凸最佳化理論）。若你要修讀證明導向課程，請
> 另外安排正式的證明寫作練習。

## English summary

This is an **editable, self-scored** progress tracker — it does **not** grade
anyone by identity. It contains: an 8-week completion table (concepts,
resources, notebook, exercises, mistakes reviewed, readiness), a 1–5
self-assessment rubric, a mistake log, and readiness checklists for four
follow-on tracks: financial algorithms, econometrics/applied regression,
time-series, and proof-heavy optimization. For the proof-heavy optimization
track the roadmap provides **only an initial diagnostic** and does **not**
replace formal, proof-based mathematical preparation.
