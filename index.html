量化金融數學
八週路線圖

一份自學取向、可重現、嚴謹的八週路線圖：從複習數學基礎，走到一個小而正確、防 leakage 的量化研究流程。

本頁面整合課程介紹、安裝步驟、八週路線圖、學習排程規劃，與可儲存的個人進度追蹤—— 讓你打開瀏覽器就能上手，快速排出符合自己節奏的學習計畫。

免責聲明： 本專案僅供教育與研究方法論用途，不構成投資建議， 所有 notebook 的結果都不代表實際可獲利或可投資的策略。

01關於本路線圖

適合誰

「具備程式設計與基礎機器學習經驗、過去學過微積分、線性代數與機率，但需要重新複習， 並建立更紮實統計、迴歸、財務數學、投資組合、時間序列與 leakage 控制回測基礎的學習者。」

這個專案「不是」什麼

  • 不是投資建議
  • 不宣稱任何可獲利策略
  • 不是進階數理金融教科書（刻意避開 HFT、進階 stochastic calculus、深度 RL）

02快速開始

本專案使用 uv 管理環境與相依套件。以下指令在 macOS、Linux、Windows、WSL 上皆可運作。

  1. 安裝 uv

    依照 uv 官方說明安裝。常見的單行指令：

    macOS / Linux / WSL：

    curl -LsSf https://astral.sh/uv/install.sh | sh

    Windows（PowerShell）：

    powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

  2. 取得倉庫並建立環境

    uv sync 會依 uv.lock 自動建立 .venv，相依套件完全可重現。

    git clone https://github.com/tingwei-chuang/quant-finance-foundations.git
cd quant-finance-foundations
uv sync --extra dev

  3. 產生合成範例資料

    所有 notebook 預設只使用合成資料、不需網路。執行下面指令以重新產生範例資料集。

    uv run python scripts/generate_synthetic_dataset.py

  4. 啟動 JupyterLab、執行測試與驗證 notebook

    uv run jupyter lab                                # 開始上課
uv run pytest                                      # 執行測試
uv run python scripts/run_all_notebooks.py         # 驗證所有 notebook 可離線執行

05每週學習流程

每一週，依以下流程進行最有效：

  1. 讀概念筆記

    先看 docs/math/ 或 docs/finance/ 的對應 cheatsheet，建立直覺。

  2. 看／讀外部資源

    跟著本頁「外部資源」段落連到官方課程，補強深度。

  3. 完成 notebook

    依序執行 cell、動手填寫 TODO 練習；遇到不懂就回去翻概念筆記。

  4. 解習題

    每本 notebook 都含概念題、程式題與反思題。完整解答在 notebooks/solutions/。

  5. 記錄錯誤

    把卡住或弄錯的地方寫進個人版的 progress_tracker.md，回顧錯誤是最有效的學習之一。

  6. 通過就緒檢查清單

    誠實打勾每週末尾的「完成本週後，你應該能做到什麼」；都通過了才前進到下一週。

08資料與隱私政策

合成資料優先

所有 notebook 預設只用 scripts/generate_synthetic_dataset.py 產生的合成資料，完全離線、可重現，本倉庫不提交任何下載的市場價格資料。

若你選擇下載真實市場資料，你必須自行遵守該資料供應商的使用條款。 下載資料夾 data/raw/ 已被 Git 忽略，請勿提交。 詳見 資料與開源政策。
