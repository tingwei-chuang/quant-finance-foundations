# 資料目錄 / Data Directory

本目錄說明本專案的資料政策。**請務必閱讀。**

## 目錄結構

```
data/
├── README.md              # 本檔案
├── sample/
│   └── synthetic_prices.csv   # 由本專案產生的合成資料（可安全提交）
└── raw/
    └── .gitkeep               # 下載的真實市場資料放這裡（不會被提交）
```

## `data/sample/` — 合成範例資料

- `synthetic_prices.csv` 由 `scripts/generate_synthetic_dataset.py` 產生。
- 它**完全由本專案產生**，不含任何第三方市場資料。
- 使用固定亂數種子（`seed = 20240101`），因此完全可重現。
- 檔案很小，可以安全地提交進 Git。

重新產生：

```bash
uv run python scripts/generate_synthetic_dataset.py
```

## `data/raw/` — 下載的真實資料（不提交）

- 此資料夾被 `.gitignore` 忽略（只保留 `.gitkeep`）。
- 若你選擇下載真實市場資料（選用步驟），請放在這裡。
- **下載的第三方資料絕對不可提交進本倉庫。**

## 資料使用條款（重要）

- 本課程的所有 notebook 與測試**預設只使用合成資料**，不需要網路連線。
- 若你選擇下載真實資料，**你必須自行遵守該資料供應商的使用條款**。
  許多供應商禁止重新散布（redistribution）其資料。
- 本專案不提供、不內建、也不背書任何特定資料供應商。
- 請參閱 `scripts/optional_download_market_data.py` 取得選用的下載指引。

## 免責聲明

本專案僅供**教育與研究方法論**用途，**不構成投資建議**。任何 notebook 的
結果都不應被解讀為實際可獲利或可投資的策略。

---

## English summary

- `data/sample/synthetic_prices.csv` is **generated by this repository** with a
  fixed seed; it contains no third-party data and is safe to commit.
- `data/raw/` is git-ignored. If you download real market data, put it there
  and **never commit it**.
- You are solely responsible for complying with the terms of use of any data
  provider you choose. This project bundles and endorses none.
- All notebooks and tests run offline on synthetic data by default.
